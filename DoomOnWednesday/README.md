# Doom on Wednesday (Quest standalone, native C++)

A fan-made horror gorilla-tag game for **Meta Quest 2 and newer**, written in C++17 with **no game engine**:
OpenXR for VR, OpenGL ES 3 for rendering, AAudio for sound. Every model, texture, font glyph and sound is
generated by code in this folder. Nothing is imported.

## Build the APK
GitHub Actions builds it on every push (`.github/workflows/dow-quest.yml`). Open the run, download the
**DoomOnWednesday-quest-apk** artifact, and sideload it (SideQuest or `adb install -r app-debug.apk`).

Locally, with Android Studio's SDK + NDK installed:
```
cd android
gradle assembleDebug        # -> app/build/outputs/apk/debug/app-debug.apk
```
The only third-party piece is the Khronos OpenXR loader (`org.khronos.openxr:openxr_loader_for_android`),
which every native Quest app needs to talk to the headset.

## Controls
- **Move by moving your arms.** Push off floors, walls and ceilings. No stick walking.
- **Grip**: grab cubes; as a monster, grab a bot's head or arm to rip it off.
- **A**: robot/chainsaw hand: transform into a chainsaw. Stalker: spore burst.
- **Right stick**: 30° snap turn.
- Poke buttons with your index finger.

## What's in the game
**Main lobby** (its own place, not a map). You spawn on the stool at the computer:
- **UP/DOWN** pick a page, letters/digits type, **OPT1-4** choose, **ENTER** confirms.
- Pages: ROOM (code), NAME, COLOR (R/G/B 0-9), VOICE, GAME MODE, MONSTER MODE, QUEUE (your monster chance, READY), STAFF.
- Turn left: the door leads to the **map vote room**. Poke a pad to vote. The READY pillar starts the round early.

**Game modes**: Be the Monster (live). Regular and Don't Splash are listed as coming soon.
OPT4 on the GAME MODE page takes you to the practice area (forms, test dummies, Mushroom OS, mod den).

**Be the Monster**
- Sub-modes: One Monster, Two Monsters, Infection (caught players turn), Shapeshifter (look like a gorilla, **B** to shift).
- Monster RNG: right after you were the monster your chance is 0%. It rises every round you aren't, so nobody is stuck as monster or never gets a turn.
- Each round: get ready, then hide (monsters are blind), then hunt for 2:30. Catch by touching; climbing out of reach saves you.
  Caught players become ghosts (or monsters in Infection). Then everyone goes back to the lobby.
- **Maps**: The Backrooms, The Poolrooms, Parking Garage, Lights Out (generated maze, head-lamp only).
- Bots fill the room until online play exists. They path through the maps; monsters hunt and survivors flee.

**Staff** (code on the STAFF page, or the keypad in the practice area): blackout, low gravity, blood moon, giant mode,
start/end round, monster rush, bot party, monster next round (owner), unlock stalker (owner), clear gore, mod den.
Default codes: owner `246810`, mod `135790`. **Change them** in `src/game/staff_codes.h`.

**The chainsaw hand** is your original `robot_arm_right.glb` with its own animations.
`tools/glb_to_dowm.py` converts it into the runtime format in `android/app/src/main/assets/`.

## Layout
```
src/core      math, procedural mesh builder
src/game      locomotion physics, collision world, game rules, gore, models, textures, font, map
src/render    GLES3 renderer (one uber-shader, instancing) and the scene/IK builder
src/audio     synthesiser (all sounds) + AAudio / null backends
src/platform  android_main.cpp (OpenXR host), desktop_main.cpp (headless test host)
android/      Gradle project (manifest has the Quest + OpenXR tags)
tests/        physics and game-rule tests
```

## How the arm physics works
Each hand is a physical sphere chasing its controller. When a surface blocks it, it stays put and the gap
between hand and controller is applied to your body: drag a planted hand back and you move forward, shove
down and you rise. Planted hands grip until you lift them. On release your body keeps the average of
its last few frames of motion (with a small boost), which gives running, jumping and wall climbs.
Arm length is capped, the body has a head and torso collider with ground friction, flights are sub-stepped
so you can't tunnel through walls, and hands are always rendered where the physics put them, so they
never sink into walls. Arms are drawn with two-bone IK from the shoulder to that hand.

## Not ported yet
- **Multiplayer and voice chat.** The web build used PeerJS (browser WebRTC). Native needs a relay server
  or a service such as Photon; the game state is ready to sync (poses, form, saw, hits).
- Hand tracking (controllers only for now).
